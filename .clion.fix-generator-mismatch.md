# Fixing CMake Generator Mismatch in CLion

If you see an error like:
```
CMake Error: Error: generator : Unix Makefiles
Does not match the generator used previously: Ninja
```

## Quick Fix

1. **Delete the build directory**:
   - In CLion: Right-click on `cmake-build-debug` → Delete
   - Or from terminal: `rm -rf cmake-build-debug`

2. **Reload CMake Project**:
   - In CLion: **File → Reload CMake Project**
   - Or click the CMake reload button in the toolbar

3. **Make sure CLion uses Ninja generator**:
   - Go to **File → Settings → Build, Execution, Deployment → CMake**
   - Check that the **Generator** field is set to **Ninja** (or leave it empty for CLion's default)
   - If it's set to "Unix Makefiles", either:
     - Clear it to use CLion's default (Ninja), or
     - Change it to "Ninja"

## Why This Happens

CLion prefers the Ninja generator (faster builds), but sometimes the build directory gets created with a different generator. The CMakeCache.txt file remembers which generator was used, and CMake doesn't allow switching generators in the same directory.

## Prevention

- Always let CLion manage the CMake configuration
- Don't manually run `cmake` in the build directory with a different generator
- If you need to switch generators, delete the build directory first
